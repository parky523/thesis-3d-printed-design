# Thesis Sub-Project: 3D-Printed Rig Design

Part of the M.Sc. thesis *Machine Learning-Enhanced Real-Time UV Spectroscopic Monitoring of Soil Nitrate* (Hochschule Furtwangen / Hahn-Schickard, Oct 2025 - Jun 2026).

Printable parts for the UV-Vis flow-cell rig, designed in Onshape: cuvette / flow-cell holders in 5.7, 5.8, 5.9 and 6 mm variants (to tune the fit), a light-tight black box, caps and a sample holder. GitHub previews each STL in 3D (`cad/`).

Main project: [uv-vis-nitrate-realtime](https://github.com/parky523/uv-vis-nitrate-realtime). Other thesis sub-projects: [thesis-arduino-autosampler](https://github.com/parky523/thesis-arduino-autosampler), [thesis-realtime-gui](https://github.com/parky523/thesis-realtime-gui), [thesis-sensor-testing](https://github.com/parky523/thesis-sensor-testing), [thesis-model-performance-testing](https://github.com/parky523/thesis-model-performance-testing).
